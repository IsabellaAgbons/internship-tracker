# Internship Tracker

This is a tool that checks for new internship postings weekly and emails a digest of what's new. It's built so I can practice data collection, automation, and eventually a small dashboard for tracking posting trends over time.

## What it does
- Pulls current internship listings from a public source
- Compares against previously seen postings to find what's new
- Emails a weekly digest of new postings
- (Planned) Dashboard showing trends: top companies, most common roles, posting volume over time

## Status
🚧 In progress — starting with the core tracker, dashboard to follow.

## Tech stack
- Python
- SQLite
- matplotlib
